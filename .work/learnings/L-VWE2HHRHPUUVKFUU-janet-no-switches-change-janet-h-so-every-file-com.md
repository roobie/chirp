# L-VWE2HHRHPUUVKFUU JANET_NO_* switches change janet.h, so every file compiled against it needs them

## Observation
The wasm target first passed Janet's feature switches as `:janet-defines`, which reach janet.c only. The image's main, generated by spork, picks between the event loop and a plain fiber run with `#ifdef JANET_EV`, which janet.h derives from JANET_NO_EV, so it still called `janet_loop` and the link failed. Natives see the same header, and stream and thread types in it depend on the switches too.

## Why it matters
`:janet-defines` suit only defines that change janet.c's behaviour without changing its header, like JANET_SPAWN_CHDIR (L-2XVJIJPBAN5P3IC6). A switch that removes a feature must go in the target's `:cflags`, so janet.c, the natives and the image main agree on one janet.h.
